# 浏览器恢复与完整分页

以本次工具返回的API文档为准。开始时刷新话题页，核对“退出”与话题卡片。用户已完成登录后，页面读取超时应作为浏览器连接故障处理，不能反复要求登录或擅自退出有效账号。

若标签编号失效，先在当前已选择浏览器列出标签，再按本次返回的ID取得句柄。某些版本的入口清单可能保留旧标签；已暴露 `browser.tabs.list()` 时，以其当前清单核对。不要把示例编号当作固定ID。若内容读取失败，按工具的浏览器故障文档尝试新句柄或可用截图；仍失败时保留断点并明确需要修复连接，不能把URL存在视为内容读取成功。

## 完整时间窗口

话题网页可能只显示5张并写“已经到底”，这不足以认证完整时间覆盖。可按项目许可，在已登录浏览器中直接导航网站公开客户端使用的话题接口，读取响应DOM。只保留以下字段：

`uniqueId, createTime, img, snakeId, sciName, cnName`

不读取用户ID、Cookie、localStorage、React内部状态或凭据存储，不在浏览器evaluate里执行网络请求。脚本中仅做DOM读取与纯计算。

当前公开客户端参数见 `assets/sync_catalog.py` 的 `fetch_page`。接口为 `/api/v2/snake/share/topics`，每页50条；使用毫秒timestamp及公开客户端MD5签名。该签名算法不是用户登录凭据，不将算法中的公开常量称为用户令牌。若站点调整接口，重新核对公开客户端，勿猜测凭据。

逐页确认响应成功、话题ID唯一、时间单调，直到页内时间早于旧断点。记录每页条数、最早/最晚时间和源站总数。冻结运行开始时间，后于该时间的记录留给下次。保留完整窗口中的元数据并与所有历史retry_topics合并复核。导出字段较多时可用纯计算校验摘要，核对本地落盘内容与浏览器读到的内容一致。

## 不可读取原图

原图失败后可尝试网站使用的全尺寸 `?x-oss-process=image/format,webp`。两者均失败时保留话题和两条尝试URL、状态、时间、原因；不得把缩略图或截图冒称已保存原图。403可能是OSS `InvalidObjectState`，可抽查错误码区分对象状态与其他故障；不绕过权限、不触发需付费的对象恢复。

可读取图片逐张排除非蛇、标签冲突和存疑内容；同一画面标注多个物种时保留复核，不能仅因URL和SHA不同就认定物种标签可靠。完整窗口已覆盖且每条均已归档、排除或持久化为可重试后，按主技能发布核验流程记录新的检查截止点。报告同时列出已保存和待处理数量。
